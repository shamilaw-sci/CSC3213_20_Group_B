# scs.pdn.ac.lk

Main public website for the Department of Statistics and Computer Science,
University of Peradeniya.

The site presents department-level public content and links visitors to related
SCS services such as the people directory, project registry, and portal.

## What It Is For

- Department homepage.
- Public department pages.
- Navigation to SCS online services.
- Department branding and public web presence.

## Related Sites

- `people.scs-pdn.space`
- `projects-scs.pdn.space`
- `portal.scs-pdn.space`

## Development

```sh
bun install
bun run dev
```

bun run lint
